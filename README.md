# Funcionários por Departamento

A aplicação apresenta uma lista de funcionários organizada por departamentos, utilizando abas para facilitar a navegação e a visualização das informações.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Desenvolvimento

Projeto desenvolvido individualmente, com orientação e apoio do professor.
